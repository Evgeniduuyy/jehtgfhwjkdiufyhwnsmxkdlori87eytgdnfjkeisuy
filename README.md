# TeleFlow

Unofficial Telegram iOS mod (fork of [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS), GPLv2).

- `TELEGRAM_COMMIT` — the Telegram-iOS commit the mod is built on
- `mod/submodules/TeleFlow` — the TeleFlow module (settings, menu)
- `mod/patches` — changes to Telegram's own code
- `.github/workflows/build.yml` — builds an unsigned IPA on GitHub's Macs

Open the menu: tap the **Chats** tab three times quickly.

The finished IPA is attached to the latest release. It is unsigned: install it with ESign, Sideloadly or TrollStore.
